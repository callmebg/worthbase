之前的家底只有一张快照：你现在有多少钱、你的东西值多少。

1.8.0 加了第三个维度——**将来的某一天，你手上能拿出多少钱。**

> 这一版几乎全部来自酷安用户 @chenyu61 的三条建议。他说的其实是同一件事，
> 只是没法命名：家底缺了「流量」。

## ✨ 新增

### 公积金不再被当成能花的钱

新增「公积金」账户类型，自动归入**受限**：算进净资产（钱确实是你的），但不算进「可用」。

没有做成开关——开关意味着你要给每个账户做一次判断，而账户类型本身已经说明了这件事。

### 定期存款有了到期日

账户可以填到期日（在添加/编辑弹窗里，紧跟「账户类型」下方）。未到期归「受限」，到期当天起自动转「可用」。只记本金，不算利息（原因见「刻意没做」）。

### 固定收支

`账户页 → 固定收支`

- **收入**：月薪、季度奖、年终奖（此前 App 里完全没有收入这个概念）
- **不依附于资产的支出**：房租、宽带、人寿险
- 按月 / 按季 / 按年填，自动折算月均，可设生效起止月份
- 车险、物业费等依附于资产的支出仍在资产详情里（算持有成本），页面顶部有一行汇总提醒你它们的存在

### 可用资金

`账户页 → 可用资金`

选一个日期，它告诉你那天你能拿出多少：

```
可用活期 + 那天之前到期的定期本金 + 累计净收支
```

公积金无论日期选多远都不计入——等得再久它也取不出来。

## 🔧 改进

### 目标达成预测重写

之前是拿最近 6 个月的净资产画一条直线往外推。年终奖这种一次性大额进账会把斜率顶飞，预计达成日期能摆动好几年；斜率为负时干脆什么都不显示。

现在**已知收支是主项，历史趋势退化成残差项**：

- 历史在跌、但每月有确定进账 → 照样给得出日期
- 真算不出来 → 明确说「按当前速度达不成」并给出缺口，不再一片空白
- 解释面板把「已知收支」和「历史残差」拆成两行，你清楚哪部分是确定的、哪部分是猜的

### 净资产构成拆成三桶

可用 / 受限 / 资产估值。

> ⚠️ **净资产总额一分未变，历史趋势线一个点也没动**——拆的只是构成。

### 账户页分组

可用 / 受限 / 负债 三组各带小计；未到期的定期挂「定期 · 未到期」标记。

## ⬆️ 升级须知

- 数据库迁移到 **v11**，纯加列加表（`accounts.maturity_date` + 新表 `cash_flows`），**不改不删任何现有数据**
- App 切后台时会自动备份；不放心的话升级前先在 `设置 → 数据` 手动导出一份 JSON
- 老备份可正常导入，缺的新字段回落为空值
- versionCode 9 → 10，可直接覆盖安装

## 🚫 刻意没做

- **利息 / 利率 / 复利**。一旦开始计息，App 就会显示一个你从没输入过的数字。家底的原则是：页面上每个数字都是你自己录进去的。定期利息相对本金是零点几个百分点，方向也确定（只会低估），不值得为它破这条线。
- **账户级「是否计入净资产」开关**。理由同上。
- **时间轴滑动条 / 多日期对比曲线**。选日期 → 给数字，够了。
- **提前支取按活期计息、大额存单/国债分类、自动转存**。那是理财产品管理器，不是家底。
- **流水记账**。只录周期性、计划性的金额。
